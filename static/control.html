Advisor

For each agent: which tier fits its work, given its real token sizes, its data profile (privacy floor), what it needs (long context, tool calls) and the canary scores. It only suggests a switch when the evidence supports it, and never below the protection its data needs.

Canary quality suite

Fixed test tasks with answers checked by code (extraction, classification, reasoning, coding, formatting, tool calls, long-context recall). The prompts are written for this suite, so none of your own data is sent. Cloud tiers cost real money (a few cents); local tiers are free. Runs show up as benchmark traffic, not as a caller.
